# Code of Conduct

This project is committed to providing a welcoming and respectful environment for contributors.

## Expected behavior

- Be kind and respectful.
- Assume good faith.
- Focus on constructive feedback.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Trolling or disruptive conduct.
- Sharing private information without consent.

## Enforcement

Project maintainers may remove or reject contributions that violate this code of conduct.
